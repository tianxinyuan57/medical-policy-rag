# 医疗政策 RAG 评估测试集

> 共 10 道题，覆盖三种场景。好的测试集 = 面试加分项。

## 设计原则

| 原则 | 目的 |
|------|------|
| 精确检索题 | 验证 Top-K 是否命中正确文件、正确段落 |
| 理解推理题 | 验证模型能否基于原文推理，而非简单复制 |
| 拒答测试题 | 验证模型在无相关原文时是否拒答（防幻觉核心） |

## 评估指标

- **检索准确率** = 命中题数 / 总题数（拒答题不计检索）
- **生成准确率** = 关键词覆盖 ≥ 50% 的题数 / 总题数
- **拒答成功率** = 正确拒答 / 拒答题总数

## 调优记录

> 每次调参都要记录"问题 → 调整 → 结果"，这就是面试黄金素材。

### 调优 #1：Top-K 对跨文件对比题的影响（2026-09-02）

**问题发现**：测试问题"医师和护士在紧急情况下的责任有什么不同？"在 K=3 时只检索到《护士条例》，完全漏掉了《医师法》，导致模型回答"无法对比"。

**定位原因**：先检查检索结果 → 3 个片段全部来自护士条例 → 定性为**检索覆盖不足**（非生成问题）。

**调整方案**：将 TOP_K 从 3 增大到 5。

**验证结果**：

| 指标 | K=3 | K=5 |
|------|-----|-----|
| 文件覆盖 | 仅《护士条例》❌ | 《护士条例》+《医师法》✅ |
| 来源文件数 | 1 | 2 |
| 回答质量 | "无法对比" | 完整三点对比分析 |

**结论**：跨文件对比题需要更大的 K 值才能保证检索覆盖度。已将默认 TOP_K 从 3 调整为 5。权衡：K 越大 token 消耗越多，但 5 个片段仍在可控范围。

**排障思路（面试复述版）**：
> "答案不对 → 先看检索结果 → 检索只找到一边 → 是检索问题不是生成问题 → 增大 K → 验证双文件覆盖 → 回答质量显著提升"
