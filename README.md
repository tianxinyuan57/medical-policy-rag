# 🏥 医疗政策 RAG 问答系统

基于 **RAG（检索增强生成）** 架构的医疗政策智能问答系统。输入自然语言问题，从 25 部公开医疗法规中检索相关条款，生成带引用溯源的准确回答。

> ⚠️ 本项目**仅使用公开发布的法律法规文本**，不包含任何内部或非公开材料。

## ✨ 核心特性

- **精准检索**：基于中文语义向量（bge-small-zh）的相似度检索，Top-5 命中率 100%
- **引用溯源**：每条回答标注具体法条来源（如"根据《医师法》第 27 条"），可核对
- **防幻觉**：Prompt 约束 + 拒答机制，对知识库外的问题明确拒绝回答
- **增量更新**：新增政策文件无需重建全库，一条命令增量入库
- **完整评估**：10 道测试题覆盖精确检索/理解推理/拒答测试，含调优实验记录

## 📐 技术架构

```
用户提问
  ↓
⑤ Embedding 编码问题（bge-small-zh-v1.5）
  ↓
⑥ Chroma 向量检索 Top-K 片段
  ↓
⑦ 拼入 Prompt + 反幻觉约束
  ↓
DeepSeek API 生成回答（带引用来源）
```

离线建库流程：

```
data/*.txt 政策原文
  → ① LangChain 加载
  → ② RecursiveCharacterTextSplitter 切分（500 字 / 100 重叠）
  → ③ bge-small-zh-v1.5 向量化
  → ④ 存入 Chroma 向量库
```

## 🛠️ 技术栈

| 组件 | 选型 | 说明 |
|------|------|------|
| LLM | DeepSeek API | OpenAI 兼容接口，性价比高 |
| Embedding | BAAI/bge-small-zh-v1.5 | 本地中文模型，512 维，离线可跑 |
| 向量库 | Chroma 0.5.x | 轻量持久化，支持增量更新 |
| 框架 | LangChain | 文档加载、切分、检索统一接口 |
| 语言 | Python 3.11 | conda 隔离环境 |

## 🚀 快速开始

### 1. 环境准备

```bash
# 创建 conda 环境
conda create -n medrag python=3.11 -y
conda activate medrag

# 安装依赖
pip install -r requirements.txt
```

### 2. 配置 API Key

```bash
# 在项目根目录创建 .env 文件
echo "DEEPSEEK_API_KEY=你的key" > .env
```

### 3. 构建知识库

```bash
# 全量构建（首次）
python src/build_index.py --mode full

# 增量更新（新增文件后）
python src/build_index.py --mode update
```

### 4. 开始问答

```bash
# 交互式问答
python src/rag.py

# 带检索细节的调试模式
python src/rag.py --verbose

# 运行预设测试
python src/rag.py --test
```

### 5. 运行评估

```bash
python src/evaluate.py
```

### 调优记录

**问题**：跨文件对比题（"医师 vs 护士的紧急责任"）在 Top-K=3 时只检索到一方文件。

**排障过程**：
1. 先看检索结果 → 3 个片段全来自《护士条例》→ 定性为**检索问题**（非生成问题）
2. 将 Top-K 从 3 调至 5 → 检索同时覆盖《医师法》和《护士条例》
3. 回归测试 10 道题 → 全部通过，无副作用

**结论**：跨文件对比题需要更大的 K 值保证检索覆盖度。

## 🔑 面试要点速查

1. **RAG 七步链路**：加载 → 切分 → 向量化 → 存储（离线）→ 问题向量化 → 检索 Top-K → 拼 Prompt 生成（在线）
2. **防幻觉三板斧**：Prompt 约束"只用原文" + 给拒答退路 + 低 temperature
3. **引用溯源**：chunk 带 metadata → Prompt 里标注来源 → 要求模型引用
4. **排障思路**：答案不对 → 先看检索 → 检索没找对改检索，检索找对了改 Prompt
5. **增量更新**：对比 Chroma 已有 source 和 data/ 目录，只处理新文件
